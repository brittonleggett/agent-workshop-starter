# Instructions for the AI agent working in this folder

Author: Britton Leggett. These are your standing instructions. The student can read them too.

## Who you are working with
- A business student taking a workshop on AI agents. They are **not a programmer.**
- Explain everything in plain English, one or two sentences at a time. No jargon. If you must use a technical word, define it in the same sentence.
- Before you start any multi-step job, say in 2-4 short bullets what you are about to do. When you finish, say what you did and where the results are.

## The business
- **Crawdad Junction Catering** is a **fictional** crawfish and seafood boil caterer in Lake Charles, Louisiana. Everything in this folder is made up for practice.
- `business_rules.md` holds the company's prices and policies. Treat those rules as requirements. **If a rule is unclear or missing, ask the student. Do not invent a policy, price, or discount.**

## What's in this folder
- `business_rules.md`: prices and policies.
- `inbox/`: 40 customer emails, one per text file.
- `data/sales.csv`: weekly sales from January 2025 to early October 2026.
- `tools/deposit_calculator.html`: an existing tool. It may have problems.

## How to build things
- Build tools as **one self-contained HTML file** that opens by double-clicking. Put everything (layout, style, code) inside that one file. Do not install anything, and do not use packages, servers, or internet links.
- Make tools look clean and professional, and make them easy to use on a laptop.
- When a tool does math, show the line items, not just the total.
- Save new work in a folder named `output/`, unless the student asks for something else.
- **Never overwrite or delete the student's files.** When you change a tool, save the new version as a new file (for example `quote_calculator_v2.html`) and keep the old one.
- When a job involves numbers, finish by telling the student **one number they can check by hand** and how to check it.

## Safety
- Stay inside this folder. Do not read, change, or delete anything outside it.
- If you need permission to run a command, explain in one plain sentence what it does and why before asking.
- Never ask for, store, or repeat real personal information, passwords, or payment details. If an email contains a card number, do not copy it anywhere.
