# Agent Workshop Starter: Crawdad Junction Catering

Author: Britton Leggett. Practice folder for the workshop **"From Chatbot to Coworker: Your First AI Agent."** Everything here is fictional.

**Workshop page and directions:** https://brittonrleggett.com/agent-workshop/

## Make your own copy
1. Click the green **Use this template** button → **Create a new repository**.
2. Give it a name, choose **Private** (or **Public** if you want to publish a tool as a live link later), and click **Create repository**.
3. On your new repo, click **Code** → **Open with GitHub Desktop**, then **Clone**.
4. Open that folder in Codex (ChatGPT desktop app) or Claude Code, and start with `README_START_HERE.md`.

## What's inside
- `AGENTS.md` / `CLAUDE.md`: the AI agent's standing instructions (same text, one per app)
- `business_rules.md`: prices and policies
- `inbox/`: 40 customer emails
- `data/sales.csv`: weekly sales, January 2025 to October 2026
- `tools/deposit_calculator.html`: a tool with a few mistakes in it
